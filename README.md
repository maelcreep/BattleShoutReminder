# Battle Shout Reminder

Small TBC Classic addon that shows a movable icon in combat when you are missing Battle Shout and lets you click it to cast.

Installation

1. Download the zip from the repository (link below) or clone this repo.
2. Put the `BattleShoutReminder` folder into your AddOns directory for TBC Classic:
   - Example path: `World of Warcraft/_classic_/Interface/AddOns/BattleShoutReminder`
3. Log into the game or use `/reload`.

TOC Interface

This addon is built for the TBC Classic interface version `20506`. If that changes for your client, update `BattleShoutReminder.toc`.

Usage

- The icon appears automatically in combat when Battle Shout is missing.
- Left-click the icon to cast Battle Shout (secure button works in combat).
- Drag the icon with left-click to move it (cannot move while in combat).
- Right-click the icon or use the Options panel to reset position.
- Slash commands:
  - `/bsreminder toggle` - enable/disable the reminder
  - `/bsreminder config` - open the Interface Options panel
  - `/bsreminder reset` - reset the icon position
